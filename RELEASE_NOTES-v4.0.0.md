# get v4.0.0 — candidate, validation in progress

get remains a query tool. v4 reduces unnecessary refusals through typed environment,
file and search readers, literal process arguments, ordinary Git status/diff snapshots,
and capability-isolated computation on supported Linux hosts.

The runtime counts actual tool starts separately from rejections and reused evidence,
repairs local failures, reserves time for a final answer, and distinguishes missing
data, differences, paging, stdout/stderr and capture limits. Defaults are six inspection
turns, sixteen starts, four concurrent calls and a 120-second automatic query deadline.
Explicit older configuration values remain respected. Cache schema 4 stores typed
plans and reauthorizes each replay.

macOS and Windows support typed readers and known host diagnostics. General scripts
remain unavailable without the complete Linux isolation backend. Git snapshot results
disable executable filters and submodule inspection and identify this limitation.

See [VALIDATION-v4.0.0.md](VALIDATION-v4.0.0.md) for the current gate status. No release
artifact is attested until its exact binary passes native and real-provider validation.
