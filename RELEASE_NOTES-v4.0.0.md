# get v4.0.0 — practical read-only queries

get remains a query tool. v4 reduces unnecessary refusals through typed environment,
file and search readers, literal process arguments, ordinary Git status/diff snapshots,
and capability-isolated computation on supported Linux hosts.

The runtime counts actual tool starts separately from rejections and reused evidence,
repairs local failures, reserves time for a final answer, and distinguishes missing
data, differences, paging, stdout/stderr and capture limits. Defaults are six inspection
turns, sixteen starts, four concurrent calls and a 120-second automatic query deadline.
Explicit older configuration values remain respected. Cache schema 4 stores typed
plans and reauthorizes each replay.

macOS and Windows support typed readers and known host diagnostics. General scripts
remain unavailable without the complete Linux isolation backend. Git snapshot results
disable executable filters and submodule inspection and identify this limitation.

The final Linux candidate completed all 120 DeepSeek tasks (40 cases × three repeats),
with zero rejected proposals. The v3.2.0 baseline completed 117/120; 26/120 tasks
encountered a policy rejection. Total query latency p50/p95 was 1.876/3.376 seconds
for v4 and 1.896/19.038 seconds for v3.2. Mean requests fell from 2.575 to 2.125,
while mean token usage increased from 5,582 to 5,988. These measurements describe
this Linux/fish corpus and service, not every possible model or workload.

Linux, macOS and Windows passed their full native gates, including CLI, HTTPS and
installer checks. Linux Bash and fish each passed 51 CLI tests. Real-model testing
also corrected missing-file evidence, failed corroboration overwriting an established
fact, repair identities and older fish startup storage.

The packaged `VALIDATION.md` records methods, Qwen compatibility trials, all earlier
failures and platform limits. `PROVIDER_VALIDATION.json` binds the complete provider
population to the exact Linux payload; assembly rejects a hash mismatch. Existing
configuration and credentials are retained. This candidate does not replace the
active installation or publish a release automatically.
